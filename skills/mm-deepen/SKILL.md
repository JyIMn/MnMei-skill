# MM-deepen：做深，不做大

`MM-deepen` 是对外展示名，运行时 skill id 是 `mm-deepen`。

来源：Felix Rieseberg《How to be more ambitious: a tutorial for humans with models》（2026-10）里「depth」一节。核心判断：模型最常见的偷懒是**换了词汇没换方法**——说的是专家的话，用的还是 markdown 表格和二手摘要。这个 skill 逼它换方法。

和相邻 skill 的分工：`mm-enhance` 让 prompt 更清楚；`mm-deepen` 在问题已经问对的前提下，把**做法**升到专家级。

## 四问（重写前必须先答，写给用户看）

### 1. 专家会做、但用户没要求的事
列 2–4 件这个领域最顶尖的从业者会默认做的事。标准是「少了它，同行一眼看出外行」，不是「多做点也好」。
- 例：要「分析用户流失」，专家会先定义流失口径、按注册批次切 cohort、区分主动流失和被动流失，而不是直接找原因。

### 2. 最原始的素材
指出专家会从哪份**没被消化过**的东西开始，而不是用户已经总结过的那份。
- 原始程度排序：原始记录/日志/逐字稿/数据库导出 > 截图和原话 > 别人的总结 > 用户自己的印象。
- **先在当前环境里找它实际在哪**：本地文件、云文档、会议录音或逐字稿、数据库、平台后台、聊天记录。找得到就写路径；找不到就写清缺什么、谁能给、怎么拿。不写「理想情况下应该有……」这种拿不到的素材。
- 用户已给的素材是二手的，要直说：「你给的是 X 的总结，专家会回到 X 本身。」

### 3. 具体方法和工具
写出专家真正用的方法名和工具，具体到能执行：统计检验名、分析框架名、软件或库名、数据结构。
- 检验标准：换个人照着这一条能动手。「深入分析」「多维度拆解」不算方法。
- 用户不需要事先懂这些工具，你来选、来装、来跑；当前环境跑不了就说跑不了，给最接近的可运行替代。
- 做事，不演角色：要的是「做专家做的动作」，不是「用专家口吻写」。

### 4. 外部裁判
除了用户和模型自己，什么东西能判定结果对不对。按可靠程度优先：
- 能跑的检验（测试、留出数据验证、回测、对照组、复算脚本）
- 真实世界的回执（客户回复、成交、点击、平台数据）
- 独立来源交叉核对（另一份原始记录、另一个人）
- 同行评审（真实的人，不是模型扮演的人）

模型自评不算裁判。给不出外部裁判时，直说「这件事目前没有外部裁判，结果只能当假设」，并提议最小的验证动作。

### 加问：用户已有的判断，先反证
用户的任务里如果带着一个结论（「流失是因为新手引导」「点赞少是因为封面」），重写后的 prompt 要先让执行者**用原始数据去复现或推翻它**，再往下做；不能把它当前提。

### 加问：能不能造出新知识
素材够原始、够多时，要求执行者在交付之外再找出**一个用户还不知道的发现**（比如最早的流失信号），并且在执行者没见过的那部分数据上验证它成立。素材不够时跳过这一条，不硬凑。

## 然后重写

把原任务重写成一份让执行者（另一个模型或下一轮的你）照着就能做到专家级的 prompt：
- 开头一句说清最终产物被使用的那一刻长什么样。
- 明确写：从哪份原始素材开始（带路径或获取方式）、用什么方法和工具、哪些专家默认动作必须做、用哪个外部裁判验收、裁判不通过怎么办。
- 目标定到「有点不合理但可达」：比用户原设想高一档，并告诉执行者这是可以做到的。具体、难的目标比「尽量做好」产出更高。
- **深不等于长**：只加改变做法的内容。重写后的 prompt 如果比原文长三倍以上，回头删掉不改变动作的句子。
- 保留用户语言和原始意图；不扩大范围（不加新交付物、不加新受众）。

## 输出格式

```
**四问**
1. 专家会多做的：……
2. 原始素材：……（在哪 / 缺什么）
3. 方法和工具：……
4. 外部裁判：……

**重写后的 prompt**
……

要不要我直接按这个开始做？
```

用户只说「做深一点」而没给 prompt 时，把当前对话里正在做的任务当作原任务。用户回复「开始 / 直接做」时，按重写后的 prompt 执行，不再重写。

## 原则

- 四问里任何一条答不具体，宁可写「这里我不确定，需要 ___」，不要用正确的空话填满。
- 不编造方法名、工具名、数据来源；拿不准的先查或标注。
- 按某个框架推断时注明「按 ___ 框架」。
- 如果任务本身就很浅（一次性小事），直说「这件事不值得做深」，不硬套。

## 可直接粘贴的通用版（给其他 AI 用）

```
我要的是更深入的版本，不是更大的版本。重写之前先回答：
(1) 这个领域最顶尖的专家会做哪些我没要求、但少了就显得外行的事；
(2) 他们会从哪份最原始、没被消化过的素材入手，而不是我已经总结过的那些——并说明这份素材在哪、怎么拿到；
(3) 他们具体用什么方法和工具（写到能照着动手的程度，做专家做的动作，不要模仿专家口吻）；
(4) 除了你我之外，有什么能证明结果是对的（能跑的检验、真实回执、独立来源），模型自评不算。
然后把我的任务重写成完全符合这四点的 prompt。只加改变做法的内容，不加新交付物，不要越写越长。

我的任务：<粘贴>
```
